# CareReady Agent Rules

Read and follow `AGENTS.md` before making changes.

This is a public repository. Never add strategy notes, working handover material, unpublished drafts, raw pilot or interview data, pricing or sales notes, credentials, personal data, or facility-identifying information to GitHub Issues, Projects, pull requests, commits, or tracked files.

Keep private work in `.private/` or another ignored path. Run `python3 scripts/check_public_repo.py --staged` before every commit and never bypass the hook.
