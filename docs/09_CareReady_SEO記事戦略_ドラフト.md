最終更新: 2026-07-15

## 1. 結論

CareReady のSEOは「ショートステイの持ち物を網羅したメディア」ではなく、**家族の準備と施設の指定がどこですれ違うかまで説明する、実用的な情報コンテンツ**を取りにいく。

現在は一般利用を広く促す段階ではない。まず身近な家族・施設で検証しながら、SEOでは将来のための検索需要とトピカルオーソリティを蓄積する。記事から本番PWAへの強いCTAはまだ置かない。

入り口キーワードは「ショートステイ 持ち物」に絞る。ただし、訴求は持ち物の数ではなく、次の4点に置く。

1. **施設ごとに必要品が違う**: 一般リストに施設ルールを重ねられる
2. **準備だけでなく帰宅時も確認する**: 置き忘れ・取り違えまで同じリストで扱う
3. **毎回再利用できる**: 紙や一回限りのメモではない
4. **登録・アプリ導入の負担が小さい設計**: 将来の一般展開時にも、未ログイン・オフラインのコア体験を維持する

競合の多くは「持ち物一覧+印刷用PDF」である。CareReady は「何を持っていくか」の情報量ではなく、**家族と施設の間で、リストを実際に回せること**で差別化する。

## 2. 誰に向けて書くか

### 一次読者

- 親のショートステイを初めて準備する家族
- 月に数回の利用で、毎回同じ準備に不安がある家族
- 兄弟姉妹・配偶者と準備を分担したい家族

### 二次読者

- 家族への持ち物説明や不足品の電話を減らしたい施設の生活相談員・介護職
- 利用開始前に家族を支援するケアマネジャー

「パーキンソン病患者の家族」は開発の原点ではあるが、SEO記事の表題ターゲットにはしない。疾患ではなく、**介護のために家から出る日の準備を担う人**という仕事で定義する。

## 3. SEOポジショニング

### ピラー記事

- 主要キーワード: `ショートステイ 持ち物`
- 準主要: `ショートステイ 持ち物リスト` / `ショートステイ チェックリスト` / `ショートステイ 準備`
- 記事の約束: 基本の必要品と、施設へ確認すべき項目が分かる

### クラスター記事候補

| 検索意図 | 記事候補 | CareReadyへの導線 |
|---|---|---|
| 初回の不安 | 初めてのショートステイ、前日までに確認したい6つ | 標準リスト |
| 数量 | 2泊3日の着替え・おむつはいくつ必要? | 施設注記・数量機能 |
| 薬 | ショートステイの薬の準備で確認すること | チェックリスト |
| 名前書き | 介護施設の持ち物にどこまで名前を書く? | 準備メモ |
| 帰宅 | ショートステイから帰った日の持ち物確認 | 帰宅チェック |
| デイサービス | デイサービスの持ち物リスト | 利用場所切替 |
| 施設職員 | 持ち物案内の電話・紙対応を整理する方法 | 施設テンプレート |

### 検索結果での差分

現在の上位結果には、介護情報メディア、施設の持参品案内、印刷用PDFが多い。持ち物の網羅性だけでは勝ちにくいため、次の差分をタイトル・導入・CTAで一貫させる。

- 施設の案内が最優先であることを明記する
- 一般リストを個人と施設に合わせて変えられる
- 「必要品を知る」で終わらず「今すぐチェックする」へつなげる
- 行きの準備と帰りの回収を一つのループとして説明する

## 4. パイを広げるプロダクト戦略

### 今は「誰でも使える持ち物アプリ」に広げない

汎用旅行・災害持出・子育てまで広げると潜在利用者数は増えるが、施設テンプレート、家族と施設の共同作業、帰宅チェックという強みが薄まる。汎用パッキングアプリと競争する段階ではない。

### 広げる単位は「病気」ではなく「ケアの移動」

同じ技術と利用体験のまま、次の順にテンプレートと記事を追加する。

1. **ショートステイ**: 頻度があり、家族と施設の両方に課題があるビーチヘッド
2. **デイサービス・通所リハ**: 持ち物は少ないが利用頻度が高い
3. **介護施設の体験入所・施設入所**: 施設固有ルールと家族説明の価値が大きい
4. **高齢者の入院・転院・リハビリ入院**: 検索需要は広いが、病院ごとのルールと制度表現の確認が必要
5. **家族間の準備分担**: B-4 の同期後に「誰が何を準備したか」へ拡張

この順序なら、ターゲットは広がるが、「介護の外出・移動準備を家族と施設の間で確実にする」というプロダクの中心は変わらない。

### 広げるかどうかの判定指標

- 記事から CareReady を開いた率
- 開いた人が最初のチェックをつけた率
- 30日以内の再利用率
- 個人項目の追加率
- 施設コード取込率
- 帰宅チェック利用率

利用者の絶対数だけでなく、**二回目も使われるか**でプロダクと検索意図の一致を判定する。

### 本文

> 公開先ではフロントマターの `title` がH1として表示されるため、本文内に同じH1は追加しない。

ショートステイの前の晩。テーブルの上に着替えを並べながら、また頭の中で確認します。

「薬は入れた。お薬手帳は。タオルは何枚だったっけ。上履きは前回と同じでいいのか」

施設からもらった紙を探し、バッグの中をもう一度見て、寝る前にまた不安になる。

持ち物の準備が大変なのは、荷物が多いからだけではありません。**何が必要かを覚え、施設のルールと照らし、入れたことを記憶しておく。** その全部が、家族の頭の中の仕事になっているからです。

## まずは、基本の持ち物リスト

ショートステイで一般的に準備候補になるものを、大きく分けると次のようになります。

### 薬・医療関係

- 常用薬、頓服薬、外用薬など、施設から指定された形で用意する薬
- お薬手帳や、薬の内容が分かるもの
- メガネ、補聴器、入れ歯とケースなど、普段使っているもの

薬の分け方や持参方法は施設によって異なります。自己判断で詰め替えず、利用先の案内と医師・薬剤師の指示を確認してください。

### 衣類

- 着替え、下着、肌着、靴下
- パジャマや寝間着
- 季節に合わせた羽織り物
- 施設から指定された室内履き

何枚必要かは宿泊日数だけでなく、洗濯の有無や利用者の状態で変わります。「日数分+予備」を目安にしつつ、最終的には施設に確認するのが安心です。

### 洗面・衛生用品

- 歯ブラシ、コップ
- フェイスタオル、バスタオル
- ティッシュ、ウェットティッシュ
- 汚れた衣類を入れる袋
- 必要な人は、紙おむつ、パッド、おしりふき

タオル、石けん、シャンプー、おむつなどは、施設側が用意する場合と家族が持参する場合があります。一般的なリストより、施設からの案内を優先してください。

### 書類・その他

- 施設から指定された介護保険・保険資格関係の書類
- 緊急連絡先が分かるもの
- 連絡帳や利用者カード
- マスク
- 本やラジオなど、施設が持込みを認めている愛用品

現金、貴重品、食品、電気製品などは、持込みにルールがあることがあります。必要かどうかも含めて、事前に確認します。

## 同じ「ショートステイ」でも、持ち物は同じではない

ここまでは、あくまで一般的な候補です。

ショートステイの持ち物は、施設によって変わります。タオルを用意してくれる施設もあれば、枚数を指定する施設もある。おむつの持参が不要な場合もある。室内履きの形や、薬の分け方に指定があることもあります。

そして、利用する人によっても違います。メガネを使う人、補聴器を使う人、とろみ剤が必要な人、落ち着くための愛用品がある人。

だから、インターネットの「完璧な持ち物リスト」を一枚見つければ終わり、とはいきません。**一般的なリストに、施設のルールとその人の必要品を重ねる。** それで、ようやく今回のリストになります。

## 要らないものも、決めておく

持ち物リストは、必要なものを追加するだけではなく、「今回は要らない」を決めるためにも使えます。

前回は必要だったけれど、今回は施設が用意する。季節が変わったので厚手の上着は要らない。使っていないものまで毎回バッグに入れると、大事なものが埋もれます。

「不要と判断した」ことが残っていれば、忘れたのではないかと何度も迷わずに済みます。

## 帰ってくる日も、持ち物の日

準備した荷物は、行きに持っていって終わりではありません。

メガネ、補聴器、薬、充電器、お薬手帳。小さくて大切なものほど、施設の棚やバッグのポケットに残ることがあります。

出発前にチェックしたリストを、帰宅時にも逆方向にたどる。それだけで、「何を持って行ったっけ」をもう一度思い出す仕事を減らせます。

## 覚えておく仕事を、リストに渡す

私は、介護の持ち物準備を支える **CareReady** というWebアプリを作っています。

ショートステイ、デイサービス、入院などの標準リストから始めて、自分の家族に必要なものを追加できます。施設からコードをもらった場合は、その施設の指定リストも取り込めます。

準備のチェック、入れた箱やバッグの記録、帰宅時の確認まで、同じリストで扱えます。

登録なしで始められること、電波の弱い場所でもチェックを続けられることを大切にしています。ただし、現在はまず身近な家族や施設と一緒に検証している段階です。

[作っている CareReady について](https://veai.jp/ja/apps/careready/)

持ち物を覚え続けるのは、家族でなくていい。次のショートステイのために、今回決めたことを、リストのほうに覚えておいてもらいましょう。
