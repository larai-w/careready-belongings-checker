# Facility-code handover observation template

This public template records only anonymised observations about the facility-code handover experiment. Do not add names, facility identifiers, care details, codes, screenshots, or raw interview notes to this repository.

## Experiment

- Issue: [#10](https://github.com/larai-w/careready-belongings-checker/issues/10)
- Hypothesis: a six-character code or QR link can fit an existing facility-to-family handover without requiring a family account.
- Scope: template creation, distribution, redemption, support recovery.
- Product decision: evidence for the existing no-login family flow; not a clinical evaluation.
