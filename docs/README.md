## 3行サマリー

1. **何を作るか**: 家族と施設の間の「持ち物準備」を確実にする介護特化チェッカー。差別化は施設ルール対応・帰宅時逆チェック・AI生成。
2. **どう広げるか**: 家族(B2C・無料)で実績を作り、施設(B2B・有料)へ入る2段ロケット。共有機能自体がバイラルループ。
3. **いくらかかるか**: 自社+AI開発なら実費 約5〜15万円/6ヶ月。外注ならフリーランス約250〜400万円、開発会社約900万円。
