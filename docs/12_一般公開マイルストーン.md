# CareReady 一般公開までのマイルストーン

最終更新: 2026-07-15

## 結論

CareReady はコアループが本番で動いているため、開発量よりも**実利用で安全性と反復利用を確かめること**が一般公開への主経路になる。

- 家族向け一般公開: 最短4〜6週間、現実的には6〜10週間
- 施設向けの有料・セルフサービス公開: 家族向け公開後、追加で1〜3か月

これは作業時間ではなく、パイロット利用を2回観察するための暦期間を含む目安である。協力者の日程により延びる可能性がある。

## マイルストーン

| 段階 | 状態 | 完了条件 | 暦期間の目安 |
|---|---|---|---:|
| M0 コアループ | 完了 | 施設作成→コード配布→家族取込→準備→帰宅確認が本番で動く | 完了済み |
| M1 安全確認 | 現在地 | パスワード変更、実機E2E、重大不具合0件 | 1〜3日 |
| M2 クローズドパイロット | 未着手 | 2〜3家族・施設で実利用し、うち複数が2回目まで使用 | 2〜6週間 |
| M3 内容・体験の改訂 | 未着手 | 持ち物34項目を現場結果で改訂し、主要な迷いと不具合を解消 | 3〜7日 |
| M4 招待制ベータ | 未着手 | 5〜10家族で配布・再利用・問い合わせ負荷を確認 | 2〜4週間 |
| M5 家族向け一般公開 | 未着手 | 公開判定ゲートを満たし、紹介ページ・記事から利用導線を開く | 3〜5日 |
| M6 施設向け正式提供 | 未着手 | アカウント発行、運用支援、価格・規約・請求方法を整える | 1〜3か月 |

M2の結果が十分に明確なら、M4は小さくするか、M3と並行してよい。反対に重大な操作上の問題が出た場合は、利用人数を増やさずM2を継続する。

## 家族向け一般公開の判定ゲート

以下を満たすまでは、`https://veai.jp/ready/` への強い一般向けCTAを出さない。

1. 認証情報を安全化し、スマートフォン実機で主要フローを完走できる
2. データ消失、別施設データ混入、認証回避などの重大不具合が0件
3. 2〜3組の協力者が実際の準備で使用し、少なくとも2回の利用サイクルを観察できる
4. デフォルト持ち物を介護職・施設側1名以上と家族側2名以上が確認する
5. 「施設指定が優先」「医療判断を代替しない」「端末データの扱い」を利用者に明示する
6. 問い合わせ先、障害時の停止・切り戻し方法、最低限のプライバシー説明がある
7. CIのフロント規約検査、バックエンド9件、コンテンツ検査、Chromeスモークが合格する

## 一般公開に必須ではない機能

- B-4 LINEログイン・家族の端末間同期
- B-5 施設向け準備状況ダッシュボード
- AIによる持ち物自動生成
- あらゆる介護・入院用途のテンプレート

これらは「ないとパイロット利用が成立しない」という証拠が出た場合だけ、M3またはM4に入れる。先に実装すると公開までの期間が延び、どの機能が反復利用に効いたか判断しにくくなる。

## 自動作業と人間ゲート

### 自動で進められること

- CIで構文、XSS規約、保存方式、Service Worker更新、データ、記事、バックエンド、画面描画を検査
- ヒアリング結果から課題分類、改訂案、優先度、次回質問を作る
- 承認済みの持ち物変更に対する `data.json` 差分、互換性検査、テストを作る
- 記事レビュー結果から公開候補、メタ説明、内部リンク案を作る
- Search Consoleや利用結果から次の用途・記事クラスター候補を比較する

### 人間が必要なこと

- パスワード変更と実機での目視確認
- パイロット協力者への連絡、同意、実利用
- 介護・医療・施設固有ルールの最終確認
- 一般公開、公開サイト変更、価格・規約の承認

人間側が手を動かせない期間も、品質基盤と資料の整備は進められる。ただしM2以降の判断材料は現場利用からしか得られないため、そこから先を開発だけで代替はしない。
