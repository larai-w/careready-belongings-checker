# CareReady マーケティング戦略

## 1. 市場とターゲット

### 市場背景
- 日本の要介護(要支援)認定者は約700万人、その家族介護者は1,000万人規模
- ショートステイ利用は年間延べ数千万件。**毎回、持ち物準備が発生する高頻度ペイン**
- 「介護 ショートステイ 持ち物」は検索ボリュームが安定して存在し、上位は施設ブログや紙のPDFリストばかり = **ツールの空白地帯**

### ペルソナ

| | 主ペルソナ: 恵子さん(58) | 副ペルソナ: 施設相談員・田中さん(34) |
|---|---|---|
| 立場 | 母(要介護3)を在宅介護。月2回ショートステイ利用 | ショートステイ受入担当。忘れ物対応が業務負荷 |
| 課題 | 毎回準備が不安。忘れると施設まで届けに行く | 家族への持ち物説明が毎回口頭+紙。不足連絡の電話が手間 |
| デバイス | スマホ(LINE中心)。アプリDLは心理障壁あり | 業務PC + 個人スマホ |
| 刺さる価値 | 「もう忘れ物で往復しない」 | 「説明業務が減る」「不足が事前にわかる」 |

**戦略上の要点: 家族(B2C)で使われる実績を作り、それを武器に施設(B2B)へ入る2段ロケット。**

## 2. ポジショニング

> 「介護の持ち物準備、これ1つで。家族みんなで、施設と一緒に。」

- 汎用TODO/パッキングアプリに対して → **介護特化**(施設ルール・名前記入・おむつ数量・帰宅時逆チェック)
- 施設の紙リストに対して → **進捗が見える・共有できる・毎回リセットして再利用できる**
- Webアプリ(PWA)であること自体が武器 → **「アプリのインストール不要、LINEで送られたURLを開くだけ」**

## 3. フェーズ別マーケティング施策

### Phase 1: 0→100ユーザー(コストほぼゼロ)
| 施策 | 内容 |
|---|---|
| コンテンツSEO | 「ショートステイ 持ち物リスト 完全版」等の記事 + そのままCareReadyで使えるテンプレボタン。**記事がそのまま製品導線になる** |
| 介護コミュニティ | X(#介護、#在宅介護)、Yahoo!知恵袋、介護系オープンチャットでの実体験ベース発信 |
| ケアマネ個人ルート | 知り合いのケアマネ・相談員5〜10名に直接配布、家族への紹介を依頼 |
| 印刷テンプレ無料配布 | PDF版リストを無料DL可に → メールアドレス/LINE友だち獲得 |

### Phase 2: 100→1,000ユーザー
| 施策 | 内容 |
|---|---|
| LINE公式アカウント | 前日リマインド配信・テンプレ配布。**このユーザー層のリテンションはLINEが最強** |
| 介護メディア寄稿 | みんなの介護、介護ポストセブン等への持込企画 |
| 施設パイロット導入 | 3〜5施設で無料導入。「施設公式テンプレ配布」機能の実証 + 導入事例記事化 |
| 口コミ設計 | 共有機能そのものがバイラルループ(家族A→家族B、施設→全利用家族) |

### Phase 3: 収益化
| モデル | 内容 | 価格感 |
|---|---|---|
| B2C フリーミアム | 基本無料 / プレミアム: AI生成・複数被介護者・家族無制限共有 | 月300〜500円 |
| B2B 施設プラン | 公式テンプレ配布・利用家族の準備状況ダッシュボード | 月3,000〜10,000円/施設 |
| 隣接展開 | 入院準備・災害持出袋テンプレで非介護層にもリーチ | — |

**主軸はB2B。** B2C単体のARPUでは事業として細いが、施設は「忘れ物対応の人件費削減」という明確なROIで説得でき、1施設が数十〜数百家族を連れてくる。

## 4. KPI

| フェーズ | 北極星指標 | 補助指標 |
|---|---|---|
| Phase 1 | 月間アクティブリスト数 | 再訪率(2回目のステイで使ったか) |
| Phase 2 | 共有実行率 | LINE友だち数、施設導入数 |
| Phase 3 | MRR | B2B解約率、プレミアム転換率 |

## 5. やらないこと

- 有料広告(Phase 2まで) — LTVが確定するまでCACをかけない
- ネイティブアプリ開発 — PWAで十分。ストア対応コストは施設導入が回り始めてから検討
- 高齢者本人向け訴求 — 使うのは家族と施設。本人向けUIは作らない
