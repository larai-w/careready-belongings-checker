# CareReady パイロットデモ & ヒアリングシート

最終更新: 2026-07-15

## 目的

30分で次の4点を確認する。

1. 持ち物内容が現場に合うか
2. 施設から家族へコードを渡す運用が成立するか
3. 次に必要なのは家族同期（B-4）か施設ダッシュボード（B-5）か
4. 有料で導入するほどの業務価値があるか

## 事前準備

- [ ] パイロットアカウントのパスワードを変更済み
- [ ] 施設管理画面にログインできる
- [ ] テストテンプレートとQR/コードを用意済み
- [ ] 家族向けPWAをスマホで開ける
- [ ] 現在の34項目を画面または印刷で見せられる
- [ ] メモと時間計測の方法を用意する

## 30分の進行

| 時間 | 内容 | 見るポイント |
|---|---|---|
| 0〜3分 | 相手の役割と現在の持ち物案内方法を聞く | 紙、口頭、電話、LINE、Webのどれか |
| 3〜8分 | 施設管理画面でテンプレートを作る | 迷う場所、入力にかかる時間 |
| 8〜12分 | QR/コードをスマホで取り込む | 家族に説明なしで使ってもらえそうか |
| 12〜16分 | 準備チェック、不要、箱分けを見せる | 本当に必要な操作と不要な操作 |
| 16〜19分 | 帰宅チェックと未返却リストを見せる | 忘れ物・紛失物対応の実態に合うか |
| 19〜25分 | 34項目と施設運用を聞く | 共通/施設固有/個人固有/不要に分類 |
| 25〜28分 | 次に必要な機能を聞く | B-4/B-5/施設オーバーライドの優先度 |
| 28〜30分 | 導入条件と価格感を聞く | 無料なら使うではなく、稟議に必要な価値 |

## 最初に聞くこと

1. 持ち物の案内は、誰が、いつ、どの方法で家族へ渡していますか
2. 家族から持ち物について電話が来るのは、月1回未満、月に数回、週に数回のどれに近いですか
3. 忘れ物や不足品があったとき、通常は誰がどのように対応しますか
4. 帰宅時の紛失や取り違えは、どの程度起きますか
5. 現在の紙リストで困っていることは何ですか

## 持ち物34項目の分類

各項目を、次のどれかに分類してもらう。話しながら `data.json` は変更せず、まずメモする。

| 分類 | 意味 | 製品での扱い |
|---|---|---|
| 共通 | 多くの施設・利用者に必要 | `data.json` に残す候補 |
| 施設固有 | この施設の提供品・指定・持込禁止による | 施設テンプレートで指定 |
| 個人固有 | 身体状況、生活、好みで変わる | 家族が個人項目として追加 |
| 不要 | 一般デフォルトにあること自体がわかりにくい、またはリスクがある | 削除または表現見直し候補 |

各項目で聞く補助質問:

- これは施設側が用意することはありますか
- 数量は施設で決まりますか、利用者で決まりますか
- 名前記入などのルールはありますか
- 忘れた場合の影響は大きいですか
- おむつ以外に「必要な人だけ表示」にしたいものはありますか

## 運用フローの確認

1. QRと6桁コードでは、どちらが家族に渡しやすいですか
2. 渡す場所は契約時、事前面談、LINE、紙の案内のどれが自然ですか
3. テンプレート更新は誰の権限にすべきですか
4. 家族がコードを取り込めない場合、どのような補助が現実的ですか
5. 紙のリストを残す必要はありますか

## 次の開発を選ぶ質問

### B-4: 家族の同期・分担

- 複数の家族が分担して準備することは多いですか
- 「誰が何を入れたか分からない」という相談はありますか
- LINEログインは家族にとって自然ですか

### B-5: 施設の準備進捗

- 利用前日に家族の準備状況が分かれば、誰が何をしますか
- 進捗率だけで判断できますか、不足品名まで必要ですか
- 施設が見ることに家族の同意が必要ですか

### 施設テンプレート拡張

- 標準項目の名前や数量を施設側で変えたいですか
- 項目ごとの注意書きは必要ですか
- テンプレートは宿泊日数、フロア、利用者種別などで複数必要ですか

## 価格・導入判断

「無料なら使いますか」ではなく、次を聞く。

1. これによって減らせそうな作業はありますか
2. 月1時間、月3時間、月5時間のどの程度が減りそうですか
3. 月3,000円、5,000円、10,000円の各価格なら、稟議で何を説明する必要がありますか
4. 導入を止める理由は、価格、家族の操作、個人情報、職員の入力負担、施設内稟議のどれですか
5. テスト導入するなら、何人・何回の利用が現実的ですか

## 判定ルール

- 1人の強い要望だけで全体仕様にしない
- 相手の要望より、実際に困った場面と現在の回避方法を重視する
- 医療・薬・制度上の表現は、ヒアリング回答だけで決めず別途確認する
- B-4/B-5は、少なくとも2〜3件の同種シグナルか、明確な実運用コミットメントが得られてから優先する
