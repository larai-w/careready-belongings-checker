## 2. 体制別コスト試算

| 体制 | 単価目安 | Phase 0 | Phase 1 | Phase 2 | 合計 |
|---|---|---|---|---|---|
| **A. 自社1人 + AI(Claude Code)** | 人件費は内部原価 | ツール費のみ | ツール費のみ | ツール費のみ | **実費 約5〜15万円**(*1) |
| **B. フリーランス1名に委託** | 80万円/人月 | 56万円 | 200万円 | 144万円 | **約400万円** |
| **C. 開発会社に委託** | 140万円/人月 + PM・ディレクション約30% | 130万円 | 455万円 | 330万円 | **約900万円** |

(*1) A案の実費内訳: Claude Code/API利用料 月1〜3万円 × 6ヶ月 + ドメイン・雑費。開発者本人の人件費・機会費用は含まない。

**AI活用の補正:** B・C案でも Claude Code 等のAIコーディングを前提にすれば実装工数は3〜4割圧縮が現実的。B案なら **250〜300万円** まで下がる見込み。逆に設計・QA・施設折衝はAIで圧縮できないため、そこは削らないこと。

## 3. 開発費以外に必要な費用

| 項目 | 金額(月額) | 備考 |
|---|---|---|
| インフラ(Cloudflare Pages/Workers/D1) | 0〜1,000円 | 無料枠でMVPは十分 |
| Claude API(リスト生成) | 従量。1生成 数円〜10円 | 月1,000生成でも数千円 |
| LINE公式アカウント | 0〜5,000円 | 通知配信数に応じて |
| ドメイン・SSL | 年2,000円程度 | careready.veai.jp ならサブドメインで0円 |
| Sentry等の監視 | 0円 | 無料枠 |
| **合計ランニング** | **月 数百円〜1万円** | ユーザー1万人規模までこのレンジ |

その他の一時費用(任意):
- 介護職監修(テンプレの専門性担保): 5〜15万円
- ロゴ・LP デザイン外注: 10〜30万円(現状のAdobe Expressロゴで当面は可)
- プライバシーポリシー等の法務レビュー: 5〜10万円

## 4. 推奨シナリオ(結論)

**A案(自社+AI)で Phase 0〜1 を進め、施設パイロットの手応えが出た時点で Phase 2 に投資する。**

| マイルストーン | 累計投下(実費) | 判断ポイント |
|---|---|---|
| Phase 0 完了(〜1ヶ月) | 〜3万円 | 家族3名が2回目も使ったか |
| Phase 1 完了(〜3ヶ月) | 〜8万円 | 「また使いたい」5人・共有実行あり |
| Phase 2 完了(〜6ヶ月) | 〜15万円 + 監修費等 | 施設パイロット3件の受諾 |

このプロダクトの支配的コストは開発費ではなく**開発者の時間と施設開拓の営業労力**。金額の大きい外注(C案)は、B2Bの需要が数字で証明されてからで遅くない。
